# JavaScript Practice & Mini Projects

A collection of JavaScript coding challenges, practice exercises, and small projects created to strengthen my programming fundamentals and problem-solving skills.

## 🎯 Objectives

- Strengthen JavaScript fundamentals.
- Practice logical thinking and problem-solving.
- Understand how JavaScript works through hands-on coding.
- Build small projects using practical programming concepts.
- Improve code readability and maintainability.

## ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.

3. Run JavaScript files using Node.js:

   ```bash
   node filename.js
   ```

   For browser-based projects, open the relevant HTML file in your browser or use the VS Code Live Server extension.
